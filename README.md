Hearth Ledger is a household budget site for the fictional Marlowe family: a November 2026 dashboard, a full transaction ledger with add/edit/delete and filtering, per-category budgets, savings goals you can contribute to, and six months of reports with hand-drawn charts. Every figure is editable and saved in the browser; nothing leaves your device. The site is plain static files under `app/` — no build step, no network requests, no framework.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser.
